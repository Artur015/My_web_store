A modern, fully responsive fashion e-commerce website built from a Figma/Pixso design mockup.
Features interactive shopping cart, product catalog, and mobile-first responsive design.

Features
Core E-commerce Features:
Interactive Shopping Cart with LocalStorage persistence
Mobile-First Responsive Design (3 breakpoints)
Product Catalog with dynamic loading from JSON
Cart Management (add/remove/update quantities)
Real-time notifications for cart actions

UI/UX Features:
Smooth Animations & hover effects
Hamburger Menu with dropdown navigation
Image Optimization with lazy loading
Modal Windows for cart and menus
Accessibility (ARIA labels, semantic HTML)

Responsive Design
Mobile (320px - 765px)
Tablet (766px - 1146px)
Desktop (1147px+)

Tools & Libraries:
BEM Methodology for CSS naming
LocalStorage API for data persistence
Google Fonts (Lato)
JavaScript

Open in browser:
Simply open index.html in your browser
Or use a local server (VS Code Live Server recommended)
